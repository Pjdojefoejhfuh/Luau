📖 Quick Start Guide

Integrate NovaAuth in 3 steps. Works with any Lua executor that supports HTTP requests.

-- 1. Get your key from the key page
-- 2. Use the NovaAuth loader for your script
local BASE_URL = "http://localhost:3000"
local SCRIPT_ID = "your_script_id_here"

-- 3. Load the loader for that specific script
loadstring(game:HttpGet(BASE_URL .. "/loader/" .. SCRIPT_ID))()

-- The loader handles:
--   • Key validation
--   • HWID locking
--   • Script delivery
--   • Expiration check

📖 Loader Integration

Each script has its own loader URL. Give your users the loader URL specific to the script they bought. 

-- Give this to your users (in Roblox executor):
loadstring(game:HttpGet("http://localhost:3000/loader/YOUR_SCRIPT_ID"))()

-- The loader UI will:
--   • Auto-detect if the script requires a key
--   • If yes -> ask the user to get/paste a key
--   • Validate server-side + HWID lock
--   • Deliver the script if valid
